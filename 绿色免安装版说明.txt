  WKF 威科夫交易智能体 V2.4 — 绿色免安装版说明
═══════════════════════════════════════════════════════════

本目录下三个 EXE 即为「绿色免安装版」：
  无需安装、无需 Python 环境，复制到任意目录双击即可运行。

【文件说明】
  Wyckoff_Analysis_GUI.exe  桌面可视化面板（推荐，双击打开）
  Wyckoff_CLI.exe           命令行分析工具（用法见下）
  Wyckoff_Feishu_Bot.exe    飞书机器人常驻后台（需飞书连接）

【使用步骤】
  1. 将本目录整体复制到目标电脑（建议放在非系统盘，如 D:\WKF）。
  2. 双击 Wyckoff_Analysis_GUI.exe 启动。
  3. 首次启动会自动创建 output\ 等目录，并弹窗引导基础配置
     （AI 模型 API Key、飞书 Webhook，跳过也可，自动降级纯规则模式）。
  4. 打开 MT5 并登录账户，软件自动连接行情。

【CLI 用法】
  Wyckoff_CLI.exe NQ 15m     分析纳指 15 分钟
  Wyckoff_CLI.exe ES 1h      分析标普 1 小时
  Wyckoff_CLI.exe XAU 5m     分析黄金 5 分钟

【配置位置】
  程序同级 config\ 目录（首次启动生成），卸载/删除时一并删除即无残留。

【卸载】
  绿色版无需卸载：直接删除整个目录即可（含配置/报告/日志，无系统残留）。

【提示】
  · EXE 已内嵌 Python 解释器与全部依赖，目标机器无需安装任何运行环境。
  · 行情数据来自本机 MT5 终端，需先行登录（GTC/Exness 等支持 CFD 的账户）。
  · 如需完整安装体验（桌面快捷方式/开始菜单/卸载程序），请使用
    installer\WKF_V2.4_Setup.exe 一键安装包。
