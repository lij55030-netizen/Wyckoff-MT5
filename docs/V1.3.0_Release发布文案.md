# WKF 威科夫交易智能体 — V1.3.0 Release 发布文案

## 🎉 V1.3.0 Release：周期扩容 · 性能修复 · 界面汉化

### ✨ 版本更新日志（V1.3.0）

#### 🕐 周期下拉扩容与排序
- 周期枚举全面扩容：新增 **1分 / 3分 / 60分 / 120分 / 240分 / 日线 / 周线**，与原有 5/10/15/30 分钟共 **11 个周期**。
- 周期参数映射：日线 = 1440 分钟、周线 = 10080 分钟，接口请求参数自动转换。
- 下拉严格固定排序（短线→长线）：1分 → 3分 → 5分 → 10分 → 15分 → 30分 → 60分 → 120分 → 240分 → 日线 → 周线。

#### 🎛 周期交互与布局适配
- 周期下拉开启**自适应宽度**：窗口缩放、高分屏、小窗口均不截断文字。
- 点击任意周期直接复用既有切换逻辑触发行情重载，不新增接口。
- 新增周期选项完整继承现有控件样式，视觉无割裂。

#### 💾 默认配置 + 品种-周期独立记忆
- 首次启动默认品种 **XAU/USD（现货黄金）**、默认周期 **5 分钟**。
- 建立「品种-周期」键值记忆：切换品种自动恢复该品种上次选用的周期；切换周期立即写入本地配置；**重启后记忆不丢失**。

#### ⚡ 切换性能深度修复
- 行情请求子线程异步执行，UI 即时响应不阻塞。
- 切换品种/周期前完整销毁旧绘图图层与指标实例，杜绝内存堆积。
- 行情订阅仅保留当前品种通道，无冗余连接。
- 新增 **K 线内存缓存**：同品种同周期重复切换命中缓存直接渲染，毫秒级响应。

#### 🇨🇳 界面文本本地化（订单流全汉化）
- 活跃方：buy/sell/none → **买方 / 卖方 / 无**。
- 反转阶段：absorption 等 → **吸收 / 吸筹 / 派发** 等中文。
- 备注固定文案：「订单流处于反转『吸收』阶段，尚需主动行为确认」。

#### ⏰ 补充功能
- **顶部北京时钟**：状态栏常驻显示北京时间 HH:MM:SS，1 秒刷新；系统时区为非东八区时自动锁定 Asia/Shanghai。
- **决策分析时间**：强制使用北京时间，与顶部时钟同一时间源。
- **问 AI 标签右侧邮箱**：静态文本「技术对接：lij55030@gmail.com」，可选中复制。
- **高概率行情提示音**：综合概率 > 60% 播放单次内置提示音；30 秒内同品种不重复响铃（防抖）；无音频文件静默不报错。*（60% = 本地铃声预警；66.5% = 飞书重点消息推送，两处阈值独立）*

#### ♻️ 历史功能全保留
倒计时 1 秒实时刷新、飞书 66.5% 概率红标推送、3 分钟推送防抖、问 AI 输入框/密钥异常弹窗、Δ 列收盘价差值、一键安装打包逻辑 —— **全部保留，零覆盖零删除**。
