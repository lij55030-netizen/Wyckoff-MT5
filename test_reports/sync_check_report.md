| 根因 | `wkf/data/mt5_source.py` 的 `fetch_mt5_bars` 使用 `copy_rates_from(mt5_sym, tf, datetime.datetime.now(), n_bars+20)` —— `date_from` 参数用**本地时间**，与 GTC 服务器时区（约 GMT+11，与本地差 3 小时）错位，取到的是**滞后 3 小时的K线**（最新停在 08-07 22:40，真实最新为 08-08 01:40） |
| 影响 | 分析软件（GUI/CLI/飞书）全部使用滞后数据，K线、指标、AI 诊断均基于过时行情 |
| 修复 | 改用 `copy_rates_from_pos(mt5_sym, tf, 0, n_bars+20)` —— 从最新K线位置向前取，无时区依赖。修复后单点验证：分析软件 close=4347.01 与交易软件 bid=4347.01 **差值 0.00** |
| 验证 | 复测三品种一致性 **7/7（100%）**；e2e 回归 **40/40 通过**；分析软件已重启生效 |
